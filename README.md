

# AVMS Hospital Management System
A robust and scalable Hospital Management System backend built using **Spring Boot**, designed to streamline healthcare operations, appointment scheduling, and patient record management.
## 🚀 Features- **Patient Management:** Register, update, and track patient medical histories.- **Doctor Scheduling:** Manage doctor availability and specialization tags.- **Appointment Booking:** Automated slot allocation and booking verification.- **Secure Rest APIs:** Role-based access control for Admins, Doctors, and Patients.
## 🛠️ Tech Stack- **Backend:** Java 17, Spring Boot, Spring Data JPA, Spring Security- **Database:** MySQL / PostgreSQL- **Build Tool:** Maven
## 💻 Getting Started### Prerequisites- JDK 17 or higher- Maven 3.6+- MySQL Server
### Installation & Setup1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Configure your database inside `src/main/resources/application.properties`.3. Build and run the application:
   ```bash
   mvn clean install
   mvn spring-boot:run
   ```
